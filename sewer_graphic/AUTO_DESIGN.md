# 관로 자동 조정 기능 설계 (초안, 미구현)

수리계산 이후 사람이 하던 일(관경·구배 조정)을 프로그램이 제안하는 기능의 설계 메모입니다.
**제안안을 보여주고 사용자가 적용 여부를 고르는 방식**이며, 되돌리기(Ctrl+Z)와 연결합니다.

## 1. 우선순위

역구배 > 통수능 > 유속 > 토피 > 지장물 이격

- 역구배(경사 ≤ 0): 절대 허용하지 않음 (hard 제약).
- 통수능 부족: **관경 자동 상향**으로 해결.
- 유속: 상하류 관저고(구배)를 조정. 지장물과 맨홀 접합(단차)은 최대한 만들지 않게 조정.
- 토피 부족: 우선 구배·관저고로 해결, 안 되면 관보호공(`-B`) 처리.
- 앞 순위는 엄격하게, 뒤 순위는 허용 여유값 안에서 위반 허용 (여유값은 설정에서 변경).

## 3. 유속 기준

- 목표 범위: 최소유속 ~ 최대유속 (오수 0.6~3.0).
- 허용 범위: PipeTools의 **유지관리 하한**까지 (오수 0.3 m/s). 0.3~0.6은 `유지관리(주의)`로 허용하되 제안 시 0.6 이상이 되도록 우선 시도.
- 우수는 하한과 유지관리 하한이 같아(0.8) 허용 폭 없음.

## 4. 부등류 필요 여부 제안 (진단 기능)

등류 결과를 보고 다음에 해당하면 "부등류로 확인 필요"로 표시:
- 방류구 외수위가 입력되어 있고 관 상단 근처 이상
- 하류 관이 거의 참(수심비 ≥ 0.8) 또는 만관
- 경사가 매우 완만(예: 3‰ 이하)
- 관경이 줄거나 단차 없는 접합으로 병목이 생기는 구간

## 5. 구현 단계

1. 진단: 등류 판정 + 부등류 필요 구간 표시
2. 통수능 부족 구간 관경 자동 상향 (규격 목록에서 한 단계씩, 하류 관경 ≥ 상류 관경)
3. 유속 보정(구배 조정), 역구배 방지
4. 토피·지장물·접합, 보호공 처리
5. 전체 연동 반복 최적화 (구배 변경 → 유속 → 유달시간 → 유량 → 통수능 재계산)

## 6. 결정 사항

- 토피: 최소 **0.4 m**까지는 확보. 그 미만이면 관보호공(`-B`).
- 지장물 이격: 해결이 안 되면 **무시**하되, 무시한 관로는 결과에 반드시 표시. (지장물 이설로 해결하는 방법도 있음)
- 관경 축소: **하지 않음** (자동 조정은 상향만).
- 상류 관경 > 하류 관경: **절대 불허**.
- 최소 경사: 별도 기준 없음. **역구배만 아니면 되고, 유속 기준으로만 판단**.
- 오수 150 mm: 자동 조정이 관경을 줄이지 않으므로, 사용자가 150으로 입력한 관만 유지. 자동으로 150을 선택하지는 않음.
- 우수 유속 허용 하한: (미정, 제안 0.6 m/s 허용 + 주의 표시, 목표 0.8)
