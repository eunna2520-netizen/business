단계 3

유달시간: 유속을 가정하고 반복

유달시간 t = t₀ + L / (60 · V) [분] t₀ = max( 상류 관로들의 유달시간, 유입시간 ) 반복: V(가정) → t → I → Q → 실유속 V' → V = V' 로 바꾸고 반복 가정유속과 실유속이 같아질 때까지

유량이 정해져야 유속이 나오고, 유속이 정해져야 유달시간이 나오고, 유달시간이 정해져야 강우강도와 유량이 나옵니다. 서로 물려 있어서 한 번에 풀 수 없고, 값이 변하지 않을 때까지 반복해서 맞춥니다.

  • 상류 관로의 유달시간이 하류 관로의 시작 시간 t₀가 되므로, 상류 오차는 하류로 누적됩니다.
  • 합류부에서는 상류 관로들 중 가장 큰 유달시간을 이어받습니다.
  • 이 프로그램은 만관유속으로 시작해 수렴할 때까지(최대 30회) 반복합니다. 막서는 초기 가정유속을 1.0 m/s로 둡니다.

단계 6

부등류: 하류 수위가 상류 관로에 미치는 영향

등류는 관로 하나를 혼자 보고 수심을 구합니다. 하류에 물이 쌓여 있으면(하천 수위가 높거나 하류 관이 작을 때) 그 영향이 상류로 올라와 수심이 위치마다 달라지는데, 이걸 구하는 것이 부등류입니다.

개념 세 가지

비에너지 E = y + V² / (2g) (관 바닥 기준 에너지 수두) 한계수심 Q² / g = A³ / T (E가 최소가 되는 수심, T: 수면폭) 프루드 수 Fr = V / √(g·A/T) Fr < 1 상류, Fr > 1 사류
  • 상류(느리고 깊음): 하류 조건이 상류로 전달됩니다. 그래서 하류에서 상류로 계산합니다.
  • 사류(빠르고 얕음): 하류 조건이 올라오지 못합니다. 상류 조건이 지배하고, 등류수심을 씁니다.
  • 등류수심이 한계수심보다 얕으면 그 관로는 경사가 급한(사류) 관로입니다.

계산법: 표준축차법

관을 짧은 구간(Δx, 프로그램은 관로당 20구간)으로 나누고, 하류 점의 수심을 알면 상류 점의 수심을 에너지 방정식으로 구합니다.

z₁ + y₁ + V₁²/2g = z₂ + y₂ + V₂²/2g + h_f h_f = (Sf₁ + Sf₂)/2 · Δx Sf = ( n·V / R^(2/3) )² (Manning 마찰경사) 모르는 값 y₁ 하나 → 이분법으로 양변이 같아지는 값을 찾음

구한 y₁을 다음 구간의 y₂로 삼아 상류로 계속 올라갑니다. 관로의 상류단 수위(관저고 + 수심)는 그 맨홀의 수위가 되고, 맨홀로 들어오는 상류 관로들의 하류 경계가 됩니다. 맨 하류 관로의 경계는 외수위(없으면 자유 유출)입니다. 영향이 없는 구간은 계산 결과가 등류수심과 같아져서, 영향 구간을 미리 나눌 필요가 없습니다.

부등류 판정

  • OVERFLOW(+m): 수위가 상류단 지반고를 넘음(맨홀 침수)
  • UP-FULL: 상류단까지 관이 가득 참 · UP-INSIDE(x): 관의 일부 구간이 가득 참
  • 수위가 관 높이 이상이면 만관 압력류로 보고 마찰손실만 계산합니다.

오수관은 하류 영향이 거의 없어 등류로 설계하는 것이 일반적이고, 부등류는 하류 수위가 높은 우수관 방류구나 펌프 흡입 수위 구간처럼 영향이 의심되는 곳에서 확인용으로 씁니다.

단계 7

횡단면(터파기)

PipeTools 횡단면도 샘플의 수량표를 역산해 맞춘 규칙입니다. 깊이는 지반(G.L.)에서 아래로 잽니다.

  • 터파기 바닥 = 관저 − 굴착하부(0.1 m). 표층+기층(0.2 m)은 터파기 폭 B로 수직 절단하고, 터파기는 그 아래부터 셉니다.
  • 오픈컷(OP): 바닥폭 = 관폭 + 2 × 이격(0.2 m), 구배 1:0.5로 올라가 B = 바닥폭 + 2×0.5×(바닥깊이 − 0.2).
  • 흙막이(GA, SP, HP): 수직, B = 관폭 + 2 × (이격 0.5 + 두께 0.15).
  • 관보호공(코드 끝 -B): 바닥 = 관저 − 0.2 m, 보호공 상자 = (관폭+0.4) × (관높이+0.4).
  • 수량: 터파기, 보조기층, 석분부설(관상단+0.2 ~ 바닥, 관 단면적 제외), 관상단 되메우기는 단면 폭이 깊이에 선형이라 사다리꼴 면적으로 셉니다.

검증됨PipeTools D200 샘플 세 단면(수직, 오픈컷, 오픈컷+보호공)의 폭, 깊이, 수량 일치.

한계

이 프로그램이 하지 않는 것, 확인하지 못한 것

  • 정상류(등류, 부등류)만 계산합니다. 호우 시계열, 펌프와 위어, 지표면 2차원 확산, LID는 다루지 않습니다.
  • 맨홀 손실계수를 넣지 않았고, BOX 표준 규격표와 개수로 전용 단면(사다리꼴, U형)은 아직 없습니다.
  • 이원환(TYPE 6), 허준행(TYPE 7), Talbot 등 General 외 강우식은 식만 구현했고 검증하지 못했습니다. 전대수다항식(TYPE 8)과 General은 검증했습니다.
  • 판정 기준값(유속, 여유율, 토피)과 횡단 기준값은 PipeTools 설정과 샘플 기준입니다. 발주처 지침이 따로 있으면 그쪽이 우선입니다.
  • PipeTools와의 비교는 사용자가 올린 샘플과 결과 파일 범위에서만 했습니다.
