# 계산 근거 (오수·우수 관로 종단 편집기)

이 문서는 `index.html`이 어떤 식과 기준으로 계산하는지, PipeTools 7.0과 어디가 다른지 정리한 것입니다.
**검증 상태**를 항목마다 적었습니다. "검증"은 PipeTools 샘플의 rpt(결과) 시트와 대조해 일치한 것이고, "미검증"은 식만 구현했거나 근거가 추론인 것입니다.

## 1. 단면 수리 (Manning)

| 항목 | 식 | 비고 |
|---|---|---|
| 유속 | V = (1/n) R^(2/3) S^(1/2) | R = A/P (동수반경) |
| 유량 | Q = A·V | 원형은 중심각 θ로 면적·윤변 계산 |
| 등류수심 | 주어진 Q, S에서 이분법 (60회) | 원형: θ를 이분, BOX: 수심을 이분 |
| 만관유량 Qfull | 원형 만관 / BOX는 **윤변 = W + 2H** (윗면 제외) | PipeTools와 같음 (검증) |
| 압송관 | 비고에 `압송`·`펌프` → 만관 압력흐름 V = Q/A, 유속·역구배·여유율 판정 없음 | 검증 |
| 다련(nb) | 1련 기준 유량 = 전체 Q / nb | |

## 2. 오수 유량 (원단위식)

- 관로 자체 인구 = 유역면적(ha) × 인구밀도
- 관로 오수량 Q_L = (오수원단위 × P.F + 지하수원단위) × 인구 / 86,400,000 + 직접유입 [m³/s]
- 상류 관로의 인구·유량은 하류로 누가합니다.
- 검증: 536개 관로 샘플에서 인구 일치, 유량 차이 0.067 m³/d 이내.

## 3. 우수 유량 (합리식)

- Q = C·I·A / 360 [m³/s] (C 유출계수, I mm/hr, A ha)
- 누가 면적과 C·A를 상류에서 하류로 합산합니다. 평균 C = ΣCA / ΣA.
- 설계유량 = 오수(직접유입 포함) + 우수.
- **유달시간** R = 유입시간 + L / (60·V) [분]. 상류 유달시간 중 최댓값을 이어받고, 관내 유속 V는 위 Q로 수렴할 때까지 반복합니다(최대 30회).
- **간선/지선**: 원형 D ≥ 700 mm, BOX는 단면적이 D700 원형 이상이면 간선, 그 아래는 지선. 간선·지선은 강우식 계수 세트가 따로 있습니다. 기준값은 수리시트 설정(`mainDia`)이며 700은 PipeTools 샘플을 관찰한 값입니다 (미검증: PipeTools 내부에서 고정값인지 설정값인지).
- 합리식은 약 2.6 km² 이내 개발지에 적합합니다 (한국방재학회지 2019, 19(5), 273~284).

## 4. 강우강도식 (t: 분, I: mm/hr)

| TYPE3 | 식 | 검증 |
|---|---|---|
| 1 General | I = a / (t^b + c) | **검증** (표준 식 사용. 아래 §8 PipeTools 차이 참조) |
| 2 Talbot | I = a / (t + b) | 미검증 |
| 3 Sherman | I = a / t^b | 미검증 (PipeTools 구 버전 rpt는 근사값으로 보임) |
| 4 Japanese | I = a / (√t + b) | 미검증 |
| 5 Semi-Log | I = a + b·log10 t | 미검증 |
| 6 이원환 | I = (a + b·log10 T) / (t^n + c) | 미검증 (PipeTools에서 오류로 계산되지 않았음) |
| 7 허준행 | I = [a + b·ln(T/t^0.2)] / [c + d·ln(√T/t) + √t] | 미검증 (PipeTools에서 오류) |
| 8 전대수다항식 | ln I = a + bL + cL² + … + gL⁶, **L = ln(t/60)** | **검증** (PipeTools 개발사 답변으로 형태 확인, rpt와 일치) |

- 전대수다항식은 국토교통부 확률강우량 자료 기반이며, 한국방재학회지(2019) 논문도 같은 6차 식을 사용합니다.
- 『설계홍수량 산정 표준지침』 인용 여부는 확인하지 못했습니다.

## 5. 판정 기준 (기본값, 수리시트 설정으로 변경)

**여유율** (오수): Q × (1 + 여유율) ≤ 허용유량
- 여유율: 관경 600 이하 100%, 700~1500 50%, 1650 이상 25% (하수도시설기준 오수관거). BOX는 2000 기준으로 25%.
- 우수·합류: 설정값(기본 0%).
- 허용유량 = 허용 수심비에서의 유량. 원형 1.0(만관), 암거 0.9. 수심비는 반올림한 3자리 수심으로 계산 (PipeTools 7.0 동작, 검증).

**유속** (오수 기본 0.6~3.0 m/s, 하한 0.3 / 우수 0.8~3.0, 하한 0.8)
- Q > 0이면 등류 실유속, Q = 0이면 만관유속으로 판정.
- 경사 100‰ 이상에서 유속 NG는 `구배10.0%이상`으로 표시 (PipeTools와 같음).
- 최소유속 미만은 유지관리(주의), 유지관리 하한 미만은 불량.
- 역구배(S ≤ 0)는 불량, 압송관은 제외.

**토피**: 관 상단 기준. 기본 1.0 m (BOX 별도). 판정은 종합판정과 **따로** 표시합니다 (지반 굴곡·지장물 때문에 토피를 줄이고 관보호공을 쓰는 경우가 있으므로). 종단파일 I열 코드 `-B`(관보호공) 구간은 토피 부족으로 세지 않고 `보호공`으로 표시합니다.

**지장물 이격**: 관 외면과 지장물 사이 연직 거리가 기준(기본 0.3 m) 미만이면 표시.

**맨홀 접합**: 유입관 하류관저가 유출관 상류관저보다 낮으면 `JOINT` (관저접합 기준).

검증: BC 노선 30관로 세 판정 일치, 오수 536관로에서 여유율·유속 536/536, 토피 535/536, 우수 14관로 모두 일치.

## 6. 부등류 (표준축차법)

- 방류구 하류단 수위에서 상류로 관로당 20구간으로 수면곡선을 계산합니다.
- 에너지 방정식: z + y + V²/2g 의 변화 = 구간평균 마찰경사 × dx (Manning).
- 사류(등류수심 < 한계수심)는 상류 지배로 등류수심을 쓰고, 하류 수위가 더 높으면 수평 수위로 둡니다. 한계수심 아래로 내려가면 한계수심 지배.
- 관이 차면 압력류로 만관 단면에서 마찰손실을 계산합니다.
- 맨홀 손실은 **고려하지 않습니다**.
- 하류 경계: 화면 입력 외수위 > 비고 `FIXED=수위` > 자유(등류수심 또는 한계수심).
- 판정: `OVERFLOW(+m)` 수위가 상류단 지반고 초과, `UP-FULL` 상류단 만관, `UP-INSIDE(x)` 관 안 일부 만관.
- 침수 맨홀: 맨홀 수위(상류단 수위, 방류구는 하류단 수위)가 지반고를 1 mm 넘으면 표시.
- 검증은 PipeTools 부등류 샘플과 대조한 정도이며, 폭넓게 검증하지 않았습니다.

## 7. 입출력 호환 (PipeTools)

- 읽기: 종단파일(옵션 2행, 머리 3행, 측점, 지장물 표), 수리계산 시트(A~AG), rpt 시트(A~AR).
- 쓰기: 종단파일 복사, 수리시트 복사, 계산결과 복사(rpt 양식).
- 30개 샘플 종단파일 왕복 시 변경 없음 (검증). PipeTools 종단면도 생성은 사용자가 직접 확인했습니다.

## 8. PipeTools 7.0과 다른 점

1. **General 강우식 (우수)**: 우수 14관로 rpt의 유달시간 R과 강우강도 I가 모두 `I = a / (b + t^c)`와 소수 둘째 자리까지 일치합니다. 표준 식 `a / (t^b + c)`는 100~130 mm/hr이 나와야 할 값인데 PipeTools 결과는 0.3~4.8 mm/hr입니다. b와 c의 역할이 바뀐 것으로 **추정**합니다. 입력 시트 원본은 보지 못했으므로 제작자 확인이 필요합니다. 이 프로그램은 표준 식을 기본으로 하고, 강우 패널에서 `a/(b + t^c)` 비교용으로 바꿀 수 있습니다.
2. **TYPE3=3 Sherman** 구 버전 결과는 근사식으로 보입니다.
3. **시계열(TYPE 9)** 계산은 PipeTools에서 실패했고, 이 프로그램은 구현하지 않았습니다.
4. **이원환·허준행**은 PipeTools에서 계산 오류가 난다고 사용자가 보고했습니다. 이 프로그램은 식만 구현했고 검증하지 못했습니다.

## 9. 한계

- 정상류(등류·부등류)만 계산합니다. 호우 시계열, 펌프, 위어, 지표면 2차원 확산, LID는 반영하지 않습니다.
- 맨홀 손실계수, BOX 표준 규격표, 관경 자동 선정의 규격 목록은 단순화되어 있습니다.
- 강우 배율은 단순 곱이며, 빈도별 계수 세트 전환은 아직 없습니다.
