# 오수관로 종단 편집기 — PipeTools 데이터 호환 메모

`index.html` 하나로 동작하는 시제품입니다. 브라우저에서 열면 업로드 자료(BC 노선: 종단파일 + 수리계산 + 결과 시트를 내장)가 뜨고, [가상 예제]로 바꿀 수 있습니다.
결과(rpt) 시트가 있으면 관로마다 PipeTools 실유속·실수심·판정과 비교한 열이 붙습니다 (BC: ΔV ≤ 0.004 m/s, 유속판정 30/30 일치).

**PipeTools 엑셀 열기**로 실제 PipeTools 파일(종단파일 + 수리계산 시트)을 불러올 수 있습니다.

## 기준 데이터

| 시트 | 역할 | 우리 쪽에서 쓰는 값 |
|---|---|---|
| `종단파일` | **기하 기준 (master)**. 노선 1개 = 시트 1개 | 누가거리, 지반고, 관저고, 관경, 맨홀, X1/Y1, 하단 지장물 표 |
| `PipeTools(노선명)` 수리계산 시트 (A~AG) | 유량·조도 등 수리 속성 | 각선면적, 조도계수, 유입유량, 인구밀도, 오수/지하 단위, P.F, 지장물 열 |
| `PipeTools(노선명)(rpt)` | 계산 결과 | 읽지 않음 (검증용으로만 비교) |

종단파일과 수리 시트는 **맨홀 좌표**(종단 X1/Y1 ↔ 수리 W/X 열, 0.25 m 이내)로 짝을 짓고,
좌표가 없으면 관로 수가 같을 때 순서로 맞춥니다. 관저고·지반고·연장은 종단파일 값을 씁니다.
둘이 0.005 m 넘게 다르면 불러올 때 "확인 사항"으로 보여 줍니다.

## 종단파일 열 해석

1행 옵션명, 2행 옵션값(HScale, Vscale, chain, 시작지반, Type, 종단분할, 라인명, 관종, 맨홀INV),
3행 열 제목, 4행부터 측점. 빈 행 다음 `측점 | INV | SIZE | TEXT …` 제목이 나오면 지장물 표.

| 열 | 제목 | 사용 |
|---|---|---|
| A | (P) | 그대로 보존. 절점 표시로 추정 |
| J | 구배 | **터파기 오픈컷 구배** (0.3 = 1:0.3). 보존, 횡단·토공에서 사용 예정 |
| K, L | INV, SIZE | 맨홀 단차 표현 (드물게 사용). 보존 |
| B | 누가거리 | 측점 위치 |
| C | 지반고 | 맨홀·측점 지반고 (토피 검토는 모든 측점에서) |
| D | 관저고 | 맨홀 관저 = 관로 끝점, 측점 관저 = 맨홀 사이 보간값 |
| E | 관경 | 관로 관경 (상류 맨홀 행 기준) |
| F | 맨홀 | 값이 있는 행이 맨홀. 맨홀 사이 = 관로 1개 |
| Y, Z | X1, Y1 | 평면 좌표. 평면도를 실제 좌표로 그림 |
| I | 구간 | 굴착 공법 코드 (`-B` = 관보호공). 읽고 쓰기 |
| 그 외 (AQ~AS 등) | | 읽지 않고 그대로 보존 |

지장물 표의 측점 `18+1.650`은 `18 × chain + 1.650` m로 환산합니다. 규격은 mm(원형) 또는 `폭*높이`(m, 박스)로 읽습니다.

## 내보내기 규칙 (엑셀로 되돌릴 때)

- **종단파일 복사**: 원래 시트의 모든 행·열을 그대로 두고, 바뀐 값만 덮어씁니다.
  - 맨홀 행 관저고 = 수정한 관저 (소수 3자리)
  - 맨홀 사이 측점 관저고 = 맨홀 관저 사이 직선 보간, **소수 2자리** (PipeTools와 같은 방식)
  - 맨홀 지반고·관경도 수정값 반영
  - 종단파일 없이 만든 노선은 맨홀 + chain 간격 측점으로 새 종단파일을 만듭니다.
- **수리시트 복사**: A~AG 전체. 불러온 행은 연장·관경·지반고·관저고만 덮어씁니다.
- 결과는 탭 구분 텍스트로 클립보드에 들어가므로 엑셀 해당 시트 A1에 붙여넣으면 됩니다
  (서식은 엑셀 쪽 것이 유지됨).

검증: 업로드된 실제 파일(노선 BC, 30관로, 종단 132행)을 불러와 수정 없이 내보낸 결과가
원본 종단파일·수리 시트와 **값이 전부 일치**. 맨홀 1개 관저를 0.10 내렸을 때는 그 맨홀 행과
앞뒤 맨홀 사이 측점 관저만 바뀜.

## 수리계산 검증 (PipeTools rpt 대비)

같은 입력(BC 노선 30관로)으로 PipeTools 결과와 비교:

- 만관유량: 상대오차 최대 0.023 %
- 실유속: 최대 차 0.004 m/s, 실수심: 최대 차 0.17 mm
- PipeTools 규칙 반영: **조도계수 빈칸은 윗행 값을 이어 씀** (BC는 첫 행 0.011만 입력)
- 유속 판정 구분을 PipeTools와 맞춤: 0.6 미만 = 유지관리(주의), 0.3 미만 = 불량 (`NG(V)0.3↓`)

샘플에서 새로 확인한 형식 (반영함):

- **단차 맨홀** = 같은 누가거리·같은 맨홀명 두 행. 1행 D = 유입관저, 2행 D = 유출관저 (I열도 각각 유입/유출 구간 공법).
  편집으로 단차가 새로 생기면 내보낼 때 맨홀 행을 하나 더 넣음.
- **O열 관번호** = 수리시트 관번호. 종단↔수리 짝짓기를 관번호 → 좌표 → 순서 순으로.
- **K/L/M열** = 그 맨홀로 들어오는 지선의 관저·관경·라인명 (지선 표기). 보존.
- **F열 'E1-…'** = 다른 노선 맨홀에 접속하는 끝점, G열(TEXT1)에 접속 맨홀 관저. 보존.
- **G열(TEXT1) '수평45' 등** = 곡관 표기. 압송관은 관저가 지반을 따라감(직선 아님).
  → 측점 관저는 "원래 값 + 양 끝 변화량 보간"으로만 바꿔서 모양을 유지하고, 안 바뀐 관로는 손대지 않음.
- 측점 관저 자릿수는 파일마다 2자리/3자리 → 원본에서 감지. 측점 관저가 빈칸이면 빈칸 유지.
- 수리시트의 조도계수·유출계수·인구밀도·오수단위·지하단위·P.F는 **첫 행에만 입력하고 아래는 이어 씀** (빈칸 = 윗행 값).
- 수리시트 AH~AP열(방류검토, BackDrop, 유입관저고/관번호, 순번, 라인명)은 보존.
- 한 파일에 수리시트가 여러 장이면(시나리오별) 첫 번째를 쓰고 나머지는 알림.

## 오수 수리계산 로직 — PipeTools 결과로 확정 (02 오수관로 + rpt, 536관로)

| 항목 | 결과 |
|---|---|
| 누가인구 | 536/536 일치 |
| 오수량 | 최대 0.067 ㎥/d 차 (반올림). 식: 인구 × (오수단위 × P.F + 지하단위) / 1000 [㎥/d] + 유입유량 |
| 만관유량 | 최대 0.007 % |
| 실유속 / 실수심 | 최대 0.008 m/s / 0.6 mm |
| 여유율 판정 | **536/536** |
| 유속 판정 | **536/536** |
| 토피 판정 | 535/536 (압송관 1개, 토피가 정확히 1.000 m인 경계 사례. 같은 조건 4개는 GOOD이라 규칙 불명) |

확정된 판정 규칙 (PipeTools와 같음):

1. **여유율**: `Q × (1+여유율) ≤ Qfull` 이면 GOOD. 역구배·무구배(Qfull=0)는 N.G. 압송관은 판정 안 함(GOOD).
2. **유속**: 판정 유속 = 실유속, 단 **유량 0이면 만관유속**.
   0.3 미만 `NG(V)0.3↓`, 0.3~0.6 `유지관리`, 0.6~3.0 `GOOD`, 3.0 초과 `NG(V)3.0↑`.
   **경사 100‰ 이상이면서 NG이면 `구배10.0%이상`** 으로 바꿈. 역구배는 `NG(V)0.3↓`.
3. **압송관** (비고 R열에 '압송'): 유속 = Q ÷ 만관단면적, 수심 표시 PUMP, 유속·역구배·여유율 판정 없음.
4. **역구배 관로 유속**: Q ÷ 만관단면적 (하한 없음).
5. **토피**: 관로 상류단 `지반고 − 관저고 − 관경 ≥ 1.0 m` 이면 GOOD.
6. 입력 시트 빈칸: 조도계수·유출계수·인구밀도·오수/지하 단위·P.F는 윗행 값을 이어 씀.

rpt의 기타(AN) 메시지 참고: `MAINT0.3`(유지관리), `LESS0.3`(0.3 미만), `SLOPE1.0%`(0.3 미만이지만 경사 10‰ 이상),
`Q-ZERO`, `Adverse Slope`, `ZERO_SLOPE`, `방류구`. 초과유량(AO) `펌프`, BACK DROP(AP) `백드롭0.05`.

## 우수 (합리식) — PipeTools 결과로 검증 (04 샘플 표준(등류) + rpt, 14관로)

| 항목 | 최대 차이 |
|---|---|
| 유달시간 | 0.001 분 |
| 강우강도 | 0.003 mm/hr |
| 우수량 | 0.00005 ㎥/s |
| 실유속 / 실수심 | 0.002 m/s / 0.2 mm |
| 만관유량 (원형·BOX) | 일치 |
| 판정 여유율·유속·토피 | 14/14 |

계산 방식 (rpt 역산으로 확인):

- 강우강도 TYPE1 General: **I = a / (t^b + c)** (매뉴얼 요약표의 a/(b+t^c)는 틀림). t = 유달시간(분).
- 계수: 이름 뒤 1 = 간선, 2 = 지선. t1 = 간선 유입시간, t2 = 지선 유입시간.
- **간선/지선 구분**: 원형 D ≥ 700 → 간선, BOX는 같은 단면적 이상 → 간선 (예제: D500 지선, D700·1×1 BOX 간선). 화면에서 기준 변경 가능.
- **유달시간**: 시작 = max(상류 관로 유달시간, 유입시간[관로 유입시간 열이 있으면 그 값]), 관로 끝 R = 시작 + L/(60·V).
  V는 실유속이라 Q와 맞물림 → 수렴할 때까지 반복(최대 30회).
- **우수량**: Q = Σ(C·A) × I(R) / 360 [㎥/s]. 평균 C = ΣCA/ΣA. 직접유량·오수량은 더함(합류 대비).
- **BOX**: 폭 열(G)이 있으면 BOX, 높이 열(H)은 m. 만관 윤변 = 폭 + 2×높이 (윗면 제외). 부분수심은 직사각형 등류.
- 판정 기본값: 우수·합류는 유속 0.8~3.0 m/s, 여유율 0 % (Q ≤ Qfull). rpt 유량 단위는 ㎥/sec.

구현했지만 rpt가 없어 미검증: TYPE2 Talbot a/(t+b), TYPE3 Sherman a/t^b, TYPE4 Japanese a/(√t+b), TYPE5 Semi-Log a+b·log t,
TYPE6 이원환 (a+b·log T)/(t^n+c), TYPE7 허준행 [a+b·ln(T/t^0.2)]/[c+d·ln(√T/t)+√t]. (TYPE8 전대수다항식은 PipeTools 개발사 답변 예제로 검증 완료)
미구현: TYPE9 시간분포(타임시리즈). (부등류·방류구 FIXED 수위는 구현됨, 아래 참고)

## 우수 추가 검증 (04 샘플 2차: 부등류·TYPE8·타임시리즈 rpt, 2026-10-12)

- **표준(부등류) rpt**: 강우강도가 4.78 mm/hr 등으로 비정상. 원인은 PipeTools **부등류 모드가 같은 General 계수를
  I = a/(b + t^c)** 로 계산하기 때문 (757.7476/(0.5809 + 10.43^2.1589) = 4.78, 간선도 1.25로 재현). 등류 모드는 a/(t^b + c).
  → PipeTools 쪽 계수 해석 불일치(버그 추정). 이 프로그램은 등류 모드 식을 사용하고 불러올 때 안내.
- **TYPE8 — 해결**: 식 출처는 국토교통부(당시 국토해양부) 전대수다항식 확률강우강도식(지점·재현기간별 계수). PipeTools 개발사(그린레이) 답변으로 계산 형태 확정: L = ln(t/60), I = exp(a + bL + cL² + … + gL⁶), t = 유달시간(분).
  답변 예제(a=4.641006 … g=−0.00089, t=10.27분 → 190.344014, t=10.274분 → 190.355495)를 이 프로그램이 **소수 6자리까지 그대로 재현**.
  PipeTools 7.0은 자체 계산에 MAKESW 내보내기용 Sherman 근사 A/(B+t)^C 변환이 잘못 적용되는 오류가 있었음(PipeTools 개발사 인정).
  샘플 TYPE8 rpt의 약 5 % 차이도 이것으로 설명됨: 지선 rpt 6점이 Sherman 곡선(A=234.4, B=−2.14, C=0.3156)에
  표시 자릿수(0.01) 이내로 맞음 → 그 rpt는 근사식으로 계산된 값.
- **타임시리즈 rpt**: 강우강도 음수(-117 등), 유량 0 → PipeTools 계산 실패. 검증 불가.
- 이원환(TYPE6)·허준행(TYPE7)은 PipeTools에서 오류로 결과 없음 (오류 메시지 확인 필요).

## 통수능 검토 화면

- 종단 표시를 "유속 / 통수능"으로 전환. 통수능 보기는 관 위 표시와 하단 표에 유량비 Q/Qfull, 여유율 상태 색.
- 통수능 검토 카드: 노선 관로별 유량비 막대 + 여유율 한계선 1/(1+여유율) (오수 D≤600 → 50 %) + 만관선 100 %.
  한계의 90 % 이상 주의, 초과 불량. 막대를 누르면 관로 선택.
- "통수능 경사 맞춤": 만관유량 ∝ √S 이므로 필요 경사 S = (Q·(1+여유율) / Qfull(S=1))² 로 하류관저 조정.

## 부등류 (표준축차법)

- 종단의 "등류 / 부등류" 전환. 수리시트 TYPE2=2 이면 불러올 때 부등류로 시작.
- 방류구 하류단 수위: 비고 `FIXED=수위` 가 있으면 그 수위, 없으면 등류수심(한계수심 이상).
- 관로마다 하류 → 상류 20구간 에너지식 z+y+V²/2g 를 마찰경사 평균으로 풀이. 맨홀에서는 하류관 상류단 수위가
  유입관 하류단 경계, 그 수위가 한계수심보다 낮으면 자유낙하(한계수심). 사류 관로는 등류수심(배수위가 높으면 수평 수위).
  관이 차면 압력류(만관 단면)로 동수경사 계속. 압송관은 만관 마찰손실만.
- 판정: 상류단 수위 > 지반고 `OVERFLOW(+초과)`, 상류단까지 만관 `UP-FULL`, 관 안 일부 만관 `UP-INSIDE(x:하류단부터 만관 길이)`.
  만관이 생기면 여유율도 N.G.
- 검증: PipeTools 부등류 rpt(강우강도는 PipeTools 오류지만 수리는 자기 유량으로 계산된 값)에 같은 유량을 넣어 비교 →
  UP-FULL 3개 일치, UP-INSIDE x = 23.02 m vs PipeTools 23.60 m, 배수위 영향 시작 관로의 하류단 수심 0.45 m 일치.
  PipeTools 부등류 rpt의 유속·수심 열은 만관 관로에도 등류 값을 적어 두어 비교 기준으로 쓰지 않음.

## 사용자 비교 파일 분석 (우리 결과 vs PipeTools 7.0, 2026-10-13)

우수 14관로 · 오수 30관로를 같은 양식으로 나란히 비교한 결과:

  PipeTools 부등류 샘플 결과와 똑같고, General 계수를 I = a/(b + t^c)로 읽을 때 나오는 값(757.7476/(0.5809+10.43^2.1589) = 4.78).

  → 반영: 허용 수심비 설정(원형 1.0, 암거 0.9)을 추가하고 허용유량·여유율 검토에 사용.

## 확인된 사항 (2026-10-07)

- 종단파일 **J열 = 터파기 오픈컷 구배** (예: 0.3 → 1:0.3). 횡단·토공 계산에 쓸 값. 지금은 그대로 보존.
- **K열 INV / L열 SIZE = 맨홀 단차** 표현이 맞지만 잘 쓰지 않음. 지금처럼 맨홀마다 관저 1개로 다루고, 필요해지면 읽기 추가.

  토피는 지반 굴곡·지장물 때문에 줄이고 관보호공을 쓰는 경우가 있어 판정과 분리.
  → 우리도 종합판정(GOOD/주의/불량)은 역구배·유속·통수능·접합으로만 내고, 토피 부족과 지장물 근접은
  별도 표시(점선 주황 표시, "토피·지장물" 열, 상단 "토피 부족 N").

- **접합 기준 = 관저접합**. 맨홀에서 유입·유출 관저를 같게 두는 것이 기본 (지금 동작과 같음).
- **종단파일 I열(구간) = 굴착 공법 코드**, 측점마다 지정. `-B`가 붙으면 관보호공.

  - 반영: 관보호공 측점의 토피 부족은 "부적합" 대신 "보호공"으로 표시. 그래픽에서 관로별 공법·보호공을
    바꾸면 종단파일 I열(그 관로의 상류 맨홀 행 ~ 중간 측점)과 수리시트 AA열에 다시 씀.

## 외수위·침수 맨홀·강우 배율 (2026-10-15)
- 종단 카드의 **외수위** 칸: 방류구 하류단 수위(하천·바다 수위, El. m). 입력하면 부등류로 바뀌고, 비우면 자유/등류. 우선순위는 화면 입력 > 수리시트 비고 `FIXED=수위` > 자유.
- **침수 맨홀**: 부등류 수위(맨홀 수위 = 상류단 수위, 방류구는 하류단 수위)가 지반고를 넘는 맨홀을 평면(빨간 원)·종단(맨홀 위 수위 표시)에 표시하고 요약 칩에 개수를 보여줌.
- **강우 ×배율**: 우수 강우강도 I 에 곱함 (확률강우 증가 검토용, 우수 계산에만 적용). 빈도별 정식 계수가 있으면 수리시트 2행 계수를 바꾸는 쪽이 정확함.
- 우수 샘플 확인: 외수위 방류구 INV+2.5 → 침수 맨홀 4곳, 지반+0.3 → 2곳. 배율 1.5 → 불량 3→8관로. 합리식 적용 범위(약 2.6 km² 이내)와 호우 시계열·펌프·지표면 2차원 확산 제외 한계는 이정민·박종표 논문(KOSHAM 2019)과 같은 수준.

## DXF 종단도 내보내기 (2026-10-20)
- 종단 카드 제목줄의 `H 1/[500] V 1/[100] [DXF]`: 지금 보고 있는 노선의 종단도를 AutoCAD용 DXF(R12 ASCII)로 저장. 파일명 `노선_종단_H500V100.dxf`.
- 좌표: 도면 단위 = m. 가로 = 측점 m 그대로, 세로 = (표고 − 기준고) × H/V (H500·V100이면 5배 과장). 1:500 용지에 출력하면 가로 1/500, 세로 1/100. 글자·간격은 용지 mm × H/1000 로 환산(글자 2.5mm, 표 행 7mm).
- 레이어: GROUND 지반선, PIPE 관, MANHOLE 맨홀, WATER 수면(부등류 켜면 수면곡선), GRID 표고 격자, TEXT, TABLE 하단 표, OBSTACLE 지장물, BRANCH 분기 유입, FLOOD 침수 맨홀, LABEL_GOOD/WARN/BAD 유속 라벨(판정색).
- 하단 표: 지반고, 관저고 유입·유출, 토피, 연장, 경사, 관경, 유속, 판정, 공법.
- 한글은 `\U+XXXX` 로 쓰고 글꼴 스타일은 `KR` = `txt.shx` + 큰 글꼴 `whtgtxt.shx` (한글 AutoCAD 기본 구성).
- 검증: 우수 예제·가상 예제 모두 ezdxf로 읽어 audit 오류 0. **AutoCAD에서 직접 열어 보지는 못함** — 한글 표시(`\U+` 해석, 큰 글꼴 유무)와 글자 겹침은 실제 AutoCAD에서 확인 필요.

## 횡단면도 (매설 단면) (2026-10-20)
- 화면 아래 **횡단면도** 카드: 현재 노선의 맨홀 위치마다 터파기 단면 + 수량표(PipeTools 횡단면도 양식: 지반고·관저고·토피고·터파기·관상단·석분부설·보조기층·포장복구 폭). `횡단 DXF` 버튼으로 AutoCAD용 시트(4열 격자, 1 unit=1 m, 글자 2.5mm = S 1:100 기준) 저장(zip).
- **PipeTools 샘플로 검증한 규칙** (D200, 횡단면도 샘플 PDF의 수량표와 대조 — 세 단면 모두 폭·깊이·수량 일치, 터파기 1.265는 0.5 올림 반올림):
  - 깊이는 G.L.에서 아래로. 터파기 바닥 = 관저 − 굴착하부(0.1). 표층+기층(0.2)은 터파기 폭 B 로 수직 절단, 터파기는 그 아래부터.
  - 오픈컷(OP): 바닥폭 = 관폭 + 2×오픈컷 이격(0.2), 구배 1:0.5로 올라가 B = 바닥폭 + 2×0.5×(바닥깊이 − 0.2).
  - 간이흙막이·SHEET PILE·H-PILE(GA/SP/HP): 수직, B = 관폭 + 2×(흙막이 이격 0.5 + 흙막이 두께 0.15). **흙막이 두께 0.15는 샘플(D200 → B=1.50)에 맞춘 값이라 다른 관경으로 확인 필요.**
  - 관보호공(`-B`): 터파기 바닥 = 관저 − 보호공 이격(0.2), 바닥폭 = 관폭 + 2×흙막이 이격(샘플 맞춤), 보호공 상자 = (관폭+0.4)×(관높이+0.4)이며 석분은 없음.
  - 수량: 터파기 = 면적(0.2→바닥), 보조기층 = 면적(0.2→0.45), 석분부설 = 면적(관상단+0.2→바닥) − 관 단면적, 관상단 되메우기 = 면적(0.45→석분 상단) (보호공은 전체 − 보호공 상자).
  - 추진(SC)·관매달기(PH)는 개착 단면 없음으로 표시.
- 기준값(굴착하부, 이격, 구배, 석분 상단, 포장 두께)은 카드의 "단면 기준"에서 바꿀 수 있음. 기본값은 사용자가 준 PipeTools 설정.
- 미검증: D200 이외 관경, 관주위 되메우기, A.S.P 파취 폭(샘플 표에서 비어 있음), BOX 관, 보호공+흙막이 조합.

## 종단 보기 조작 (2026-10-21)
- 휠 = 커서 기준 확대·축소(가로·세로 같이), Shift+휠 = 가로만, Ctrl+휠 = 세로만. 휠 버튼 드래그 또는 Space+드래그 = 이동(가로 스크롤 + 세로 범위). Home = 전체(세로 자동맞춤 복귀), F = 크게 보기(종단 카드를 화면 가득, Esc 로 닫기), 제목줄 `⛶ 크게` 버튼.
- Ctrl+Z / Ctrl+Y(또는 Ctrl+Shift+Z) 되돌리기·다시하기 (200단계). 글자 입력칸에서는 기본 동작 유지, 숫자 입력칸·선택칸에 커서가 있어도 앱 되돌리기로 동작. 단계 수를 토스트로 표시. 되돌리기 대상은 관로 편집(관저·관경·BOX 규격 등)이며 외수위·강우 배율 같은 설정값은 제외.
- 모바일 두 손가락 확대는 아직 없음 (＋/－ 버튼과 좌우 스크롤 사용).
- (2026-10-21) **H:V 비율 고정**: 종단 화면의 세로 배율 = 가로 배율 × (H/V). 휠 확대·축소, 이동, 크게 보기를 해도 제목줄 `H 1/500 V 1/100` 비율(5배 과장)이 그대로 유지됨 (Shift/Ctrl 휠로 한 축만 확대하던 기능은 비율이 깨져서 뺌). 제목줄의 `화면 H 1/xxx · V 1/yyy`는 지금 화면의 실제 축척(96dpi 근사), `축척대로` 버튼 또는 H 값을 바꾸면 가로가 1/H 크기로 맞춰지고, V 값을 바꾸면 세로 과장만 바뀜. `전체`는 노선 전체 맞춤(비율은 유지).
