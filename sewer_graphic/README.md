# 오수관로 종단 편집기 — PipeTools 데이터 호환 메모

`index.html` 하나로 동작하는 시제품입니다. 브라우저에서 열면 업로드 자료(BC 노선: 종단파일 + 수리계산 + 결과 시트를 내장)가 뜨고, [가상 예제]로 바꿀 수 있습니다.
결과(rpt) 시트가 있으면 관로마다 PipeTools 실유속·실수심·판정과 비교한 열이 붙습니다 (BC: ΔV ≤ 0.004 m/s, 유속판정 30/30 일치).

**PipeTools 엑셀 열기**로 실제 PipeTools 파일(종단파일 + 수리계산 시트)을 불러올 수 있습니다.

## 기준 데이터

| 시트 | 역할 | 우리 쪽에서 쓰는 값 |
|---|---|---|
| `종단파일` | **기하 기준 (master)**. 노선 1개 = 시트 1개 | 누가거리, 지반고, 관저고, 관경, 맨홀, X1/Y1, 하단 지장물 표 |
| `PipeTools(노선명)` 수리계산 시트 (A~AG) | 유량·조도 등 수리 속성 | 각선면적, 조도계수, 유입유량, 인구밀도, 오수/지하 단위, P.F, 지장물 열 |
| `PipeTools(노선명)(rpt)` | 계산 결과 | 읽지 않음 (검증용으로만 비교) |

종단파일과 수리 시트는 **맨홀 좌표**(종단 X1/Y1 ↔ 수리 W/X 열, 0.25 m 이내)로 짝을 짓고,
좌표가 없으면 관로 수가 같을 때 순서로 맞춥니다. 관저고·지반고·연장은 종단파일 값을 씁니다.
둘이 0.005 m 넘게 다르면 불러올 때 "확인 사항"으로 보여 줍니다.

## 종단파일 열 해석

1행 옵션명, 2행 옵션값(HScale, Vscale, chain, 시작지반, Type, 종단분할, 라인명, 관종, 맨홀INV),
3행 열 제목, 4행부터 측점. 빈 행 다음 `측점 | INV | SIZE | TEXT …` 제목이 나오면 지장물 표.

| 열 | 제목 | 사용 |
|---|---|---|
| A | (P) | 그대로 보존. 절점 표시로 추정 |
| J | 구배 | **터파기 오픈컷 구배** (0.3 = 1:0.3). 보존, 횡단·토공에서 사용 예정 |
| K, L | INV, SIZE | 맨홀 단차 표현 (드물게 사용). 보존 |
| B | 누가거리 | 측점 위치 |
| C | 지반고 | 맨홀·측점 지반고 (토피 검토는 모든 측점에서) |
| D | 관저고 | 맨홀 관저 = 관로 끝점, 측점 관저 = 맨홀 사이 보간값 |
| E | 관경 | 관로 관경 (상류 맨홀 행 기준) |
| F | 맨홀 | 값이 있는 행이 맨홀. 맨홀 사이 = 관로 1개 |
| Y, Z | X1, Y1 | 평면 좌표. 평면도를 실제 좌표로 그림 |
| I | 구간 | 굴착 공법 코드 (`-B` = 관보호공). 읽고 쓰기 |
| 그 외 (AQ~AS 등) | | 읽지 않고 그대로 보존 |

지장물 표의 측점 `18+1.650`은 `18 × chain + 1.650` m로 환산합니다. 규격은 mm(원형) 또는 `폭*높이`(m, 박스)로 읽습니다.

## 내보내기 규칙 (엑셀로 되돌릴 때)

- **종단파일 복사**: 원래 시트의 모든 행·열을 그대로 두고, 바뀐 값만 덮어씁니다.
  - 맨홀 행 관저고 = 수정한 관저 (소수 3자리)
  - 맨홀 사이 측점 관저고 = 맨홀 관저 사이 직선 보간, **소수 2자리** (PipeTools와 같은 방식)
  - 맨홀 지반고·관경도 수정값 반영
  - 종단파일 없이 만든 노선은 맨홀 + chain 간격 측점으로 새 종단파일을 만듭니다.
- **수리시트 복사**: A~AG 전체. 불러온 행은 연장·관경·지반고·관저고만 덮어씁니다.
- 결과는 탭 구분 텍스트로 클립보드에 들어가므로 엑셀 해당 시트 A1에 붙여넣으면 됩니다
  (서식은 엑셀 쪽 것이 유지됨).

검증: 업로드된 실제 파일(노선 BC, 30관로, 종단 132행)을 불러와 수정 없이 내보낸 결과가
원본 종단파일·수리 시트와 **값이 전부 일치**. 맨홀 1개 관저를 0.10 내렸을 때는 그 맨홀 행과
앞뒤 맨홀 사이 측점 관저만 바뀜.

## 수리계산 검증 (PipeTools rpt 대비)

같은 입력(BC 노선 30관로)으로 PipeTools 결과와 비교:

- 만관유량: 상대오차 최대 0.023 %
- 실유속: 최대 차 0.004 m/s, 실수심: 최대 차 0.17 mm
- PipeTools 규칙 반영: **조도계수 빈칸은 윗행 값을 이어 씀** (BC는 첫 행 0.011만 입력)
- 유속 판정 구분을 PipeTools와 맞춤: 0.6 미만 = 유지관리(주의), 0.3 미만 = 불량 (`NG(V)0.3↓`)

## 워크플로우 목표와 현재 상태

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | CAD에서 관로 라인 작성 | CAD 쪽 (예정: 플러그인) |
| 2 | 체인 생성(속성 블록) + 지반고 입력 또는 TIN/서피스 자동 추출 | CAD 쪽 (예정) |
| 3 | 절점 체인에서 맨홀·곡관 XYZ 추출 → 종단파일 | **종단파일 읽기/쓰기 완료** |
| 4 | 수리계산 그래픽에서 관저 조정 | **완료** (드래그, 연동/단독, 구간 일직선, 모바일) |
| 5 | 수정 데이터로 종단면도·횡단면도 생성 | 다음 단계 (DXF 출력) |
| 역방향 | 엑셀 데이터만으로 라인 다시 그리기 | 좌표가 종단파일에 있으므로 DXF 출력 시 함께 |

## 확인된 사항 (2026-10-07)

- 종단파일 **J열 = 터파기 오픈컷 구배** (예: 0.3 → 1:0.3). 횡단·토공 계산에 쓸 값. 지금은 그대로 보존.
- **K열 INV / L열 SIZE = 맨홀 단차** 표현이 맞지만 잘 쓰지 않음. 지금처럼 맨홀마다 관저 1개로 다루고, 필요해지면 읽기 추가.
- **토피 기준 1.0 m 이상이 적합**. 단 PipeTools의 GOOD은 역구배·유속·통수능만으로 내는 종합판정이고,
  토피는 지반 굴곡·지장물 때문에 줄이고 관보호공을 쓰는 경우가 있어 판정과 분리.
  → 우리도 종합판정(GOOD/주의/불량)은 역구배·유속·통수능·접합으로만 내고, 토피 부족과 지장물 근접은
  별도 표시(점선 주황 표시, "토피·지장물" 열, 상단 "토피 부족 N").

- **접합 기준 = 관저접합**. 맨홀에서 유입·유출 관저를 같게 두는 것이 기본 (지금 동작과 같음).
- **종단파일 I열(구간) = 굴착 공법 코드**, 측점마다 지정. `-B`가 붙으면 관보호공.
  - OP01~06 OPEN CUT, GA01~06 간이흙막이, SP01~06 SHEET PILE, HP01~06 H-PILE, SC01~06 추진, PH01~06 관매달기
  - 뒤 2자리: 01 토사, 02 ASP, 03 CONC, 04 보도블럭, 05 ASP+CONC, 06 ASP국도
  - 수리시트 AA열은 `코드,연장` (예: `OP02-B,50`)
  - 반영: 관보호공 측점의 토피 부족은 "부적합" 대신 "보호공"으로 표시. 그래픽에서 관로별 공법·보호공을
    바꾸면 종단파일 I열(그 관로의 상류 맨홀 행 ~ 중간 측점)과 수리시트 AA열에 다시 씀.
- 횡단·종단 도면(DXF) 양식은 CAD 연결 단계에서 정함.

## 변경 추적

불러온 시점의 관저·지반·관경·공법을 기억해 두고, 달라진 셀을 계산표에서 강조합니다.
상단 "변경 N" 버튼을 누르면 `관로 항목 이전값 → 새값` 목록이 나옵니다. 엑셀에 붙여넣기 전 확인용.

## 아직 확인 중

- AQ~AS 열(측점명 / 지반고 / 맨홀명): AR 지반고가 C열과 다른 행이 있음(예: No.58 C=32.34, AR=89.96).
  AR이 서피스(TIN) 추출값이고 C가 보정값인지.
- 맨홀 이름 체계: 수리 시트 `BC-01` / 종단파일 `M2-SD-01`. 화면에는 수리 시트 이름을 씀.
